# AGENTS.md — Standing Rules for OneGate / PS18
Read `docs/UI_PLAN.md` and `docs/PS18_Loop_Prompts_and_Handoff_UX.md` before touching any UI.

## Golden Rules
- Exclusively Light Mode Liquid Glass (stacked blur + refraction + reflection on light canvas wash).
- Cap concurrent blurred layers at 3-4 per viewport.
- All 13 UX states from Part 1 must be strictly represented.
- Time must always be formatted as a range + clock time ("About 15 to 25 min, by 2:40 PM").
- Friendly support levels only ("Level 2 specialist"), never raw internal tiers or scores.
- Zero debug console chrome or watermark in production UI.
